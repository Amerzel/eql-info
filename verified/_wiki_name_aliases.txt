# Wiki page name aliases.
#
# Some spells exist on eqlwiki.com under a slightly different title than the
# canonical name in our spells_us.txt data. This file maps the EQL-data name
# to the actual wiki page title so that:
#   - the spell-page generator emits links to the correct wiki URL
#   - missing-page checks don't get tripped up by character differences
#
# Format:  our-DB-name | wiki-page-title
# Lines starting with # are comments; blank lines are ignored.
# Both sides are matched case-sensitively (matching wiki convention).
#
# ====================================================================
# PERMANENT ALIASES — wiki is canonical, our DB has artifacts
# ====================================================================

# Backtick → apostrophe (EQL data files use backtick as a substitute for ').
