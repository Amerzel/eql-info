What's in each spell

  • name, icon, spell_type, skill
  • description (rendered) and description_template (raw #N/%z placeholders)
  • mana, range, cast_seconds, fizzle_seconds, recast_seconds
  • duration (+ duration_ticks), target, resist
  • classes — verified classes + levels
  • effects — per slot: effect_id, effect, base, limit, formula, max (raw signed; negative = damage/decrease)
  • messages — cast-on-you / cast-on-other / wears-off

Not included (sourced by hand on the wiki): the spellicon letter code, kind, location / where-to-obtain, other.
