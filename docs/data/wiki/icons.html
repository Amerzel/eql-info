EQL Spell Icons — Wiki Comparison

For every verified in-game spell, this page shows two icons side by side: the icon currently rendered by the wiki via spellicon = X on its {{Spellpage}}, and the actual in-game icon extracted from the EQL client's Spells##.tga sheets (the icon the player sees in their spellbook). When these differ, the wiki entry is wrong and should be updated.

Key finding: EQL renders icons numerically from Spells##.tga sheets (cells of 40×40, 6×6 per sheet) using the spell file's new_icon field as a 0-indexed cell number. The wiki's 22 letter icons (Spellicon_A–V) are a classic-EQ approximation that groups multiple distinct in-game icons into the same letter — and some in-game icons (e.g. the blue group-portal used by Druid Circle teleports, cell 130) have no wiki letter at all.

Per-spell data: spell_icons.json contains the full mapping with cell IDs, sheet positions, and the wiki's current spellicon for each spell — for the team to script against.
Icon addressing reference (how to find any icon)

Each Spells##.tga sheet is 256×256 pixels arranged as a 6×6 grid of 40×40 cells (36 cells per sheet, with 16px padding on the right and bottom). To find the icon for a spell with new_icon = N:

  1. The actual cell index is cell = N + 1 (the spell file is 0-indexed; our extracted PNGs are 1-indexed).
  2. The sheet number is (N // 36) + 1 — so cells 0–35 are in Spells01.tga, 36–71 in Spells02.tga, etc.
  3. Within the sheet, local = N % 36, then row = local // 6, col = local % 6, with pixel box (col*40, row*40, col*40+40, row*40+40).
