Spell Icons — Default vs Alternate Sets

EQL's Options window offers four spell-icon sets (“Spell Gem Tex”: Default + Alternate 1/2/3). This page shows all 145 icon ids used by in-game spells in each set, keyed by the spell file's new_icon field. Rows are grouped by icons that are identical in the Default set (19 such groups). Red-bordered groups get different art per id in an alternate set — Alternate 1 and 2 have unique art for every id, so Default's duplication is a property of that skin, not of the game's icon ids.
